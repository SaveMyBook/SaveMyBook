# SaveMyBook 部署清單（2026-09-29）

照順序做一次即可。**API 與 App 必須一起上線**：API 版本升為 15，AI 同意說明也改為第 4 版，舊版 App 的書櫃流程與 AI 同意都會無法使用。

## 一、本機：commit

建議分三個 commit：

1. `savemybook_api`
2. `savemybook_app`
3. `documents/`、`Diagrams/`

注意事項：

- `savemybook_api/test/uploads/` 會出現為新檔案，請一起 commit。原本 `.gitignore` 的 `uploads/` 連測試資料夾也排除了，已改為只排除根目錄的 `/uploads/`。
- 不要 commit：
  - `.env`
  - Firebase 服務帳戶 JSON、APNs `.p8`
  - Android keystore、`key.properties`
  - `savemybook_app/.claude/`

## 二、伺服器：資料庫（在更新程式之前）

1. 備份：
   ```
   mysqldump -u 帳號 -p savemybook > ~/savemybook-before-20260929.sql
   ```
2. 先只上傳 `savemybook_api/prisma/schema.prisma`。
3. 預覽變更（Prisma 7 的寫法，舊的 `--from-url` 已不能用）：
   ```
   npx prisma migrate diff --from-config-datasource --to-schema prisma/schema.prisma --script
   ```
   - 預期大多是 `CREATE TABLE`、`ADD COLUMN`，包括書櫃、先行存書、通行密鑰、AI 等資料表。
   - 若出現 `DROP` 刪到有資料的表或欄位，先停下來確認。
4. 套用變更：
   ```
   npx prisma db push
   ```
5. 產生 Prisma client：
   ```
   npx prisma generate
   ```

## 三、伺服器：API

1. 以 SFTP 上傳整個 `savemybook_api`，但排除 `node_modules`、`.env`、`uploads/`、`backups/`。
   - 這版的 `package.json` 沒有新增套件。若伺服器上的 `package.json` 和這版不同，執行 `npm install --omit=dev`。
2. `.env`：
   - `CABINET_SIMULATOR=true`：要用網頁模擬書櫃（`/kiosk`）測試時開啟。改回 false 後，模擬書櫃的憑證會失效。
   - `FCM_SERVICE_ACCOUNT_FILE`：指向重新下載的 Firebase 服務帳戶金鑰。之前刪掉的那份，要到 Firebase 主控台重新產生。
   - 不需要其他新的環境變數。
3. 重新啟動 API，用你平常的方式。
4. 驗證：
   - `npm run verify`：檢查環境變數與資料表欄位是否齊全，缺欄位會列出來。
   - `npm run smoke`
   - 瀏覽器開 `https://api.savemybook.today/kiosk`，應出現「配對碼」畫面。
     - nginx 若是把整個網域轉給 API（`/.well-known` 打得開就是），就不用另外設定。

## 四、App

1. 在 `pubspec.yaml` 調整版本號後打包 iOS、Android。
2. iOS 的 `Info.plist` 定位用途說明已更新為「用於使用智慧書櫃時確認您位於書櫃旁」。送審時若被問到定位用途，照這個說明回覆。
3. 新 App 要與新 API 同時上線。

## 五、上線後在後台

1. **法律文件**
   - 發布第 3 版服務條款與隱私權政策，選「重大更新」。
   - 全文與發布方式在 `條款第3版發布稿.md`，可直接貼上。
   - 使用者下次開啟 App 時須重新同意，AI 功能的同意也會重新詢問一次。
2. **常見問題**：把第 1、2、5 題改為 `常見問題更新.md` 的文字。
3. **AI 設定**：確認「書籍顧問每日上限」為 20。程式預設已是 20，但之前若在後台存過 30，要改回來。
4. **書櫃配對**（每台書櫃都要做；沒配對的書櫃只能手動回報）：
   1. 開啟 `/kiosk`，畫面會顯示 8 位配對碼。
   2. 在 App 進入「管理後台 → 書櫃 → 書櫃裝置 → 配對裝置」。
   3. 輸入配對碼。
5. **補審的 AI 費用**：上線後的前幾個小時，最近 7 天上架、沒有審核紀錄的書會各補審一次，每 10 分鐘 20 本。這是一次性的費用。
