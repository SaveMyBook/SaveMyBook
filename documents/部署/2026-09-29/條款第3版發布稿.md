## 發布方式

本次採**重大更新**。服務條款、隱私權政策均由第 2 版升為第 3 版，全體會員須重新同意。

### 一、發布前須完成

1. **程式部署**：依部署清單先執行 `prisma db push`，再同步上線新版 API 與 App。撤回 AI 同意時刪除上架輔助建議紀錄的修正，已包含在這版程式中。
2. **App 同意說明**：已隨這版程式改為第 4 版（上架輔助的傳送欄位、對話與處理紀錄的保存說明，六語系），不需另外處理。
3. **發布時點**：新版程式上線後立即發布。書櫃掃碼、定位等規定自程式上線起即已實施。

### 二、後台操作

兩份文件各操作一次，並於同一時段連續發布。

1. 以具「公告與文件」權限的管理員登入 App，進入「管理後台 → 法律文件」，點選「服務條款」。
2. 切換至「純文字」，全選既有內容後，貼上下方「服務條款全文」程式碼區塊內的文字（不含 ``` 標記）。標題維持「服務條款」。
3. 切換至「預覽」，確認第 1 至 12 條分段正確。第 3 條第 (1) 至 (13) 款應屬同一條。
4. 按「儲存」，檢視「變更摘要」後，於「更新方式」選「重大更新」。
   - 確認版號顯示「第 2 版 → 第 3 版」。若正式站現行版號不同，以畫面所示為準，仍選「重大更新」。
   - 按「發布並通知」。通知送出後無法撤回。
5. 點選「隱私權政策」，重複步驟 2 至 4。儲存畫面另會提示「使用者亦須重新同意 AI 資料處理，才能繼續使用 AI 功能。」
6. 不可選「小幅修改」：選「小幅修改」時版號不變，也不會要求使用者重新同意。

```

建議文字：

```
本平台將盡力維持系統正常運作，但對上述情況所造成之不便或損害，除可歸責於本平台之事由外，不負賠償責任。
