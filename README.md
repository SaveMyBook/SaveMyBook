# 救『舊』我的書 - 智慧二手書交易系統 

## 📝 專案介紹
「救『舊』我的書」是一個創新的二手書交易系統 。 本專案旨在解決傳統二手書交易中資訊輸入繁瑣、書況評估不易以及交易信任等痛點 。

## 🏗️ 系統架構
為維持程式碼整潔與擴充性，請採取多 Server 架構進行功能解耦
