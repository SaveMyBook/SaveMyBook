- ① 和 ② 是 S7 與簡介複評前言共同主打的兩件事（寄送／面交），數字最大、技術最硬（書櫃＋暫管），兩張海報現有的大圖都能直接接上。

### 4-3 沒有乾淨出處的地方
- **預付款詐騙沒有問卷數字**：問卷只問了面交的「放鳥或詐騙」（43.2%），沒有問線上預付款被騙。海報不能把 43.2% 寫成「預付款詐騙」；② 的問題要寫成「面交：擔心遇到放鳥或詐騙」＋動機句，分開標示。
- **書況落差沒有「問題」的數字**：95% 衡量的是「看照片有幫助」，屬於對解法的需求，不是「書況不符的發生率」。③ 的問題欄建議用 README 動機句，95% 放在旁邊當佐證。
- **Q-e 隱私 25.9%、Q-g 物流時間 42.1%**：只有間接的解法句（「買賣雙方無須碰面」概述 二；「非同步」），沒有專門針對這兩項的句子。建議不要上海報。
- **「無人駐守的安全問題」**：只來自評審建議（S5／P6）和 S21 講稿，不是問卷，也不是動機。放上海報時要標明是設計問題。
- **成效無法證明問題已解決**：見 §3 末段注意事項。
- **「撥款規則」標籤、「四道開櫃驗證」「賣家存書五步」小標**：本來就是規劃用字（出處對照表已註記），改版時如果改成問題導向的小標（例如「免寄送」），也要另外找出處或標為結構標籤。
