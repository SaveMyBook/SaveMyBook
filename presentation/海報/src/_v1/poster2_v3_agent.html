01專題動機與目的

Project Purpose

學生之間的二手書交易常遇到幾個問題：
面交時間難以配合、書況描述與實物有落差、預付款後可能遭遇詐騙。

  • 簡化交易流程
  • 打破時空限制
  • 提升使用體驗
  • 促進資源循環
  • 強化交易安全

02問題描述

Problem Statement

二手書交易，難在哪裡？

  1. 57.9%

    寄送

    需自行包裝、跑超商寄貨

    57.4%書櫃功能認為「24 小時自助」最具吸引力 51.4%交易方式傾向使用「實體儲物櫃」方案

    1智慧書櫃免寄送

    書櫃依場域開放時間（最長24小時）無人化運作，
    買賣雙方無須約定面交時間。

  2. 43.2%

    面交

    擔心遇到放鳥或詐騙

    2先驗收、後撥款

    款項由平台暫管，買家確認書況
    或取書24小時爭議期屆滿後才撥款，降低詐騙與糾紛風險。

  3. 逾95%

    線上看書況

    認為「線上查看實體書況照片」
    對購買意願具有正面幫助

    3拍張照片，AI 判斷書況與售價

    書況照片上架、取書當下驗收，
    並輔以24小時爭議期與管理員仲裁，降低圖文不符糾紛。

  4. 35%

    處理書籍

    想清空但懶得處理

    4AI 降低上架負擔

    ISBN掃描結合AI上架輔助，自動帶入書目
    並建議書況、分類與售價，大幅降低上架門檻。

資料來源：本團隊二手書交易需求調查，有效問卷 498 份。
